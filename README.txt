ВИДЕОУРОКИ — БРАУЗЕРНЫЙ ПРОТОТИП

1. Распакуйте архив.
2. Положите свои MP4-видео в папку videos с именами lesson-1.mp4 ... lesson-5.mp4.
3. В index.html в массиве lessons задайте названия и кодовые слова.
4. Разместите папку на статическом хостинге или запустите локальный HTTP-сервер из папки проекта: python -m http.server 8000. Откройте http://localhost:8000.

Кодовые слова должны быть заранее добавлены в сами видео при монтаже. Сайт их не встраивает.
Первый урок открыт, остальные открываются по одному. Поле кода доступно только после окончания видео. Регистр и пробелы по краям не учитываются.
Скорости: 0,75 / 1 / 1,25 / 1,5 / 2. Повторный просмотр начинается с начала. Положение воспроизведения между перезагрузками не сохраняется, факт завершения и открытые уроки сохраняются в localStorage. Очистка данных браузера сбрасывает прогресс.

ОГРАНИЧЕНИЯ
Это стартовый прототип, не защищённая платформа. Видео не включены. Код не проходил проверку в реальных браузерах. Нативные панели отключены, используются свои кнопки, обычная перемотка блокируется; поведение системных медиакнопок может отличаться между устройствами. Через инструменты разработчика ограничения можно обойти. Пароли и пути к видео доступны в исходнике. localStorage можно изменить вручную.
Для реального ограничения доступа нужны сервер, авторизация, серверное хранение прогресса и кодов, проверка запросов на видео и защищённая выдача файлов. Серверная проверка не доказывает внимание зрителя и не исключает запись экрана.
